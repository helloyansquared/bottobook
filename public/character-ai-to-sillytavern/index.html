How to move your Character.AI chats to SillyTavern

Drop your official Character.AI export ZIP on BotToBook, open a chat, type the character's name and yours as SillyTavern shows them, check who said what, and press SillyTavern chat. You get a .jsonl chat file. In SillyTavern, open that character, choose Manage chat files, then Import chat. Messages keep the dates and times recorded in your export.

Steps

  1. Get your export. Request it in Character.AI settings (Profile Settings → Account → Manage Account & Data → Export Data). It can take 3–4 weeks; the ZIP's password is your account email in lowercase.
  2. Open it in BotToBook. Every chat appears on the left, longest first, with its first line so you can tell them apart.
  3. Set the names. Type the character's name exactly as it is (or will be) in SillyTavern, and your own name as your SillyTavern persona. SillyTavern keeps the names in the file as they are.
  4. Check who said what. The export doesn't record the sender, so BotToBook works it out from turn order and reply timing. Read the first few messages and press Swap who said what if a chat came out backwards.
  5. Press SillyTavern chat. One chat at a time is free. With Pro, tick several chats and you get them all as separate files in one ZIP.
  6. Import it. In SillyTavern, create or import the character first, open it, then Manage chat files → Import chat and pick the .jsonl file. You can select several files at once. The imported chat appears in the list with “imported” in its name.

What the file contains

A SillyTavern chat file (.jsonl) in the format SillyTavern itself saves: a header line, then one line per message with the speaker's name, whether it was you, the date and time from your export, and the text with Character.AI's *actions* and **bold** kept as they are.

{"chat_metadata":{},"user_name":"unused","character_name":"unused"}
{"name":"Wren","is_user":false,"is_system":false,"send_date":"2026-10-03T19:02:11.204Z","mes":"*The lamp room hums.* You made it.","extra":{}}
{"name":"Sam","is_user":true,"is_system":false,"send_date":"2026-10-03T19:03:40.551Z","mes":"I almost did.","extra":{}}

What doesn't come across

  • The character itself. A chat file is only the conversation. For characters you made on Character.AI, character.json in your export holds the greeting and definition to paste into a new SillyTavern character. As far as we know, characters made by other people aren't in it.
  • Alternative replies (swipes), memory and persona settings. BotToBook doesn't carry these over.

BotToBook opens the export in your browser and never uploads it or connects to Character.AI or SillyTavern. The file is generated on your device.

Questions

How do I move Character AI chats to SillyTavern?

Drop your Character.AI export ZIP on BotToBook, open a chat, type the character's name and yours as SillyTavern shows them, check who said what, and press SillyTavern chat. In SillyTavern, open that character, go to Manage chat files and choose Import chat. Messages keep the dates recorded in your export. One chat at a time is free; Pro saves all selected chats in one ZIP.

Does the SillyTavern chat file include the character?

No. A SillyTavern chat file holds only the conversation, and it has to be imported into a character that already exists in SillyTavern. Create the character there or import its card first. If it is a character you made on Character.AI, its greeting and definition are in character.json in your export, ready to copy.

Why doesn't the Character AI export say who wrote each message?

Character.AI's official export lists each message's text, chat ID and time, but not whether you or the character wrote it, and not the character's name. BotToBook works out the sides from turn order and reply timing, since characters answer within seconds, and you can swap the sides or type the names yourself.

Can I move Character AI chats to another account or app?

As far as we know, Character.AI offers no way to import an export into another account or back into the app. You can move chats to SillyTavern: BotToBook turns each chat in your export into a SillyTavern chat file that you import into the matching character there. You can also keep them readable as a PDF, EPUB or text file.

What files does BotToBook open?

The official Character.AI export (the ZIP, or message.json, character.json and user.json from inside it), CAI Tools exports (JSON and Tavern JSONL), SillyTavern .jsonl chats, and most JSON files that hold a list of messages. When a file does record who spoke, BotToBook uses that instead of guessing. It saves chats as PDF, EPUB, HTML, text or SillyTavern chat files.
