What is message.json in a Character.AI export?

message.json is the file in a Character.AI data export that holds your chats. It is one list of every message from all conversations, each with a chat_id, candidate_id, raw_content and create_time. It does not record who wrote a message or the character's name, which is why it needs a viewer.

Fields in message.json

An entry looks like this (values made up):

{
  "chat_id": "a1b2c3d4-…",
  "candidate_id": "e5f6…",
  "raw_content": "*She sets down the lantern.* You came back.",
  "create_time": "2026-10-03 19:02:11.204188+00:00"
}

chat_id ties the message to a conversation. raw_content is the text, with Character.AI's Markdown (*actions*, **bold**) left in. create_time has microsecond precision. Some exports are a single JSON array; others put one message per line.

What the export leaves out

There is no field for whether you or the character wrote a message, and no character name — not even for the characters you talked to. character.json only lists characters you created yourself.

How viewers rebuild your conversations

  1. Group messages by chat_id.
  2. Sort each group by create_time.
  3. Work out who spoke. Turns alternate, and the character's replies arrive within seconds while yours take longer, so the gaps between messages show which side is which. BotToBook does this and lets you swap the sides with one click.
  4. Name the speakers: you type the character's name once per chat.

character.json and user.json

character.json holds the characters you made — name, greeting and the long definition. user.json holds your profile, such as your first name and the date you joined.

Questions

How do I read message.json from a Character AI export?

Open it in a viewer rather than a text editor. message.json holds every message from all your chats in one list, so a viewer has to group messages by chat_id, sort them by create_time and work out who spoke. Drop the file on BotToBook to see each conversation in order.

What fields are in Character AI message.json?

Each entry in message.json has a chat_id that groups it into a conversation, a candidate_id for the reply, raw_content with the message text, and create_time, a timestamp with microsecond precision. There is no field for who wrote the message and no character name, so those have to be inferred or typed in.

Why doesn't the Character AI export say who wrote each message?

Character.AI's official export lists each message's text, chat ID and time, but not whether you or the character wrote it, and not the character's name. BotToBook works out the sides from turn order and reply timing, since characters answer within seconds, and you can swap the sides or type the names yourself.

What does "Export Data" on Character AI mean?

Export Data is Character.AI's official way to get a copy of what your account holds. You request it in settings, and Character.AI emails a link to a ZIP containing user.json (your profile), character.json (characters you created) and message.json (every message from all your chats). It is raw data, not a readable transcript.
